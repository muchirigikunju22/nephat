🎯 COMMON TASKS

  Add GitHub link to a project:
  → Edit src/data/portfolio.js
  → Find the project's links array
  → Add: { text: "⌥ GitHub", url: "https://github.com/..." }
  → Save (auto-reloads!)

  Add website/demo link:
  → Edit src/data/portfolio.js
  → Add: { text: "🌐 Website", url: "https://myproject.com" }

  Change colors:
  → Edit src/styles/portfolio.css
  → Search for :root { --accent: ... }
  → Change color values

  Add new project:
  → Edit src/data/portfolio.js
  → Copy an existing project object
  → Modify the values
  → Add to projects array
